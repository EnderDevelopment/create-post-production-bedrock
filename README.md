# Create Port Mod

The Create Port Mod is a Minecraft mod that ports the Create Post productions mod from Java Edition to Bedrock Edition, ensuring compatibility with the Vatonage Create mod. This mod aims to bring the powerful mechanics and features of Create to the Bedrock platform, enhancing the gameplay experience for Bedrock players.

## Install

1. Download the mod from the GitHub repository or the EnderDevelopment marketplace.
2. Place the downloaded `.jar` file into the `mods` folder of your Minecraft Bedrock Edition installation.
3. Launch Minecraft Bedrock Edition and ensure the mod is loaded correctly.

## Use

1. Launch Minecraft Bedrock Edition.
2. Create or load a world where you want to use the Create Port Mod.
3. Explore the new mechanics and features introduced by the mod, such as kinetic mechanisms, logistical systems, and decorative blocks.
